## Overview

Most form automations send the same generic confirmation 
to everyone. This workflow reads what the client actually 
asked for and writes a tailored email response — 
instantly, with no manual work.

## Workflow Steps

1. Client submits consultation form
2. Data is logged to Google Sheets
3. AI reads the specific service request
4. Gmail sends a personalized 1-1 email in seconds

## Tech Stack

| Tool | Purpose |
|---|---|
| n8n / Zapier | Workflow automation |
| Google Gemini | AI Agent / Chat Model |
| Google Sheets | Data logging |
| Gmail | Email delivery |

## n8n vs Zapier — Quick Comparison

| | n8n | Zapier |
|---|---|---|
| AI Agent control | More flexible | Simpler setup |
| Setup time | Longer | Faster |
| Cost | Self-hostable | Subscription |
| Best for | Complex logic | Quick builds |

## Who This Is For

Freelancers and agency owners who want to automate 
client onboarding without losing the personal touch.
